1. Read `.project-management/hub-pointer.md` and take the value of its `**Project ID:**` line.
2. If the file is missing or has no project id, tell the user "No Hub project in this directory — run /holycode-hub:init" and stop. If any Hub call in this command answers 403 `FORBIDDEN_CREDENTIAL_ORG`, this sign-in belongs to a different organisation than this directory's project: show the Hub's message verbatim (it names the organisation), tell the user to sign in to the Hub again and choose that organisation on the Hub's organisation page (reconnect the `holycode-hub` MCP server so its sign-in opens — in Pi: `/holycode-hub:login`), and stop — never repeat the call or switch to another project. If any Hub result in this command carries `client_outdated`, first tell the user this Pi package is outdated — installed `client_outdated.installed`, published `client_outdated.published` — and to run `/holycode-hub:update`, then run `/reload` in Pi; give no other update steps.
3. Run `node "$HOME/.holycode-hub/pi/scripts/effort-capture.mjs" take` — it prints the effort measured since the last report as a JSON array (timestamps, actor and category only; never prompt text or code). When it prints `[]` or fails, tell the user there is nothing new to report and stop.
4. Call the `work_progress` tool on the `holycode-hub` MCP server exactly once with `{ "project_id": "<that id>", "story_id": "$ARGUMENTS", "segments": <that array> }`.
5. On success tell the user how many segments were reported; on `FORBIDDEN_CLAIM` tell them they do not hold this story's lease; on `VALIDATION_EFFORT_SEGMENT` report the Hub's message (it names the segment); on any other error report the code + request id. **Next step:** end your reply with one line that starts with `Next:` — `Next: keep working the story, then /holycode-hub:verify <key>`. Make no further Hub calls for this step.

**Pi: print only what the step reports** — in Pi each Hub tool call runs inside a `codemode` script, and only what the script prints reaches you. A Hub tool call there resolves to the MCP result, so the Hub's answer is its `structuredContent` (`const result = (await tools.mcp__holycode_hub__<tool>(args)).structuredContent`). Never print the whole result (`text(JSON.stringify(result))`, `return result`): print only the fields this command reads or reports, as one object of just those fields (`text({ <field>: result.<field>, … })`), plus `client_outdated` whenever a result carries it; when a call fails, print the error's code and message. The Hub extension shows each Hub call to the developer as one line (`✓ <tool> 160ms`, or ✗ with the Hub's error code and message); Ctrl+O expands it to the script and its output.
